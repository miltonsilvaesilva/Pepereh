# Pepereh
Think Big

Website institucional da PEPEREH – Comércio e Serviços, Lda. (Luanda, Angola),
feito com Jekyll e publicado no GitHub Pages.

- `index.html`: página inicial (PT; tradução EN em `script.js`)
- `noticias/`, `_posts/`: secção Notícias (um ficheiro por artigo e por idioma)
- `privacidade/`, `termos/`: textos legais
- `_data/contactos.yml`: email, WhatsApp, horário, redes sociais, agenda e estatísticas
- `_layouts/`, `_includes/`: estrutura comum das páginas
- `styles.css`, `script.js`, `assets/`: estilos, código e imagens
- `.pages.yml`: painel de edição (Pages CMS)
- `.claude/skills/noticias-pepereh/`: skill de preparação semanal de notícias
