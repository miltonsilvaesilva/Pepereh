# Pepereh
Think Big

Website institucional da PEPEREH – Comércio e Serviços, Lda. (Luanda, Angola).

- `index.html`: página única (PT, com tradução EN em `script.js`)
- `styles.css`: estilos responsivos
- `script.js`: idioma PT/EN, menu móvel, formulário de email e WhatsApp
- `assets/`: logótipos e ícone
- `docs/briefing.md`: respostas do briefing

Para activar o WhatsApp, edite `WHATSAPP` no início de `script.js` (só dígitos, ex.: `244923000000`).
